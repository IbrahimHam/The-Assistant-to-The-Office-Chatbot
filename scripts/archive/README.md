# 🗃️ Archive – Prototypes & Experiments

This folder contains **archived files and experiments** that were explored during development but are **not used in the final version** of the Assistant to The Office Chatbot.

They're preserved here for transparency, reference, and to acknowledge team contributions.

---

## 📁 Folders & Contents

### 🧪 `chatbots/`

Early chatbot implementations and testing scripts.

| File                    | Description                                |
| ----------------------- | ------------------------------------------ |
| `DG_Chatbot_300_100.py` | Prototype using 300-token chunks           |
| `DG_Chatbot_400_100.py` | Prototype using 400-token chunks           |
| `DG_Chatbot_500_100.py` | Prototype using 500-token chunks           |
| `IH_Chatbot_Scene.py`   | Scene-based prototype using notebook logic |

---

### 📒 `notebooks/`

Notebook-based experiments and utilities.

| File                       | Description                                             |
| -------------------------- | ------------------------------------------------------- |
| `Agents.ipynb`             | Agent-based chatbot exploration using **Mistral**       |
| `OFFICELLamaRAG.ipynb`     | LLM + RAG test using Office data                        |
| `scene_embedding.ipynb`    | Early embedding pipeline (used to test console version) |
| `Feature Engineerin.ipynb` | Deprecated notebook (now merged into main EDA notebook) |

📦 `requirements_agents.txt` is located in the same folder for setting up `Agents.ipynb` (not used in production).

---

## ❗ Note

These files are **not used in the final backend or web app**.  
Please do not edit or rely on them unless you're specifically exploring or reviving past ideas.

If you need to test something from here, do so in isolation and avoid mixing it with production components.
